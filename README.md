# Flock

Flock is a real-time chat application designed for seamless and instant communication. With a focus on simplicity, speed, and reliability, Flock enables users to connect and collaborate effortlessly.

## Features

- **Instant Messaging:** Real-time chat with friends, family, or teams.
- **Group Chats:** Create and manage groups for shared conversations.
- **Servers:** Create Servers for communities or friends.
- **Typing Indicators:** Know when someone is responding in real-time.
- **Customizable Themes:** Personalize your chat experience.
- **Secure Communication:** End-to-end encryption to keep conversations private.
- **Cross-Platform:** Available on web, desktop, and mobile.

## Installation

### Prerequisites

Ensure you have the following installed on your system:

- Node.js (v16 or later)
- npm or yarn

### Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/galfar-coder/Flock.git
   cd flock
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run start
   ```

4. Access the app at [`http://localhost:3000`](http://localhost:3000).

## Usage

1. Sign up or log in to your Flock account.
2. Start chatting with your contacts.
3. Create servers for collaborative conversations.
4. Customize your profile and chat themes.
